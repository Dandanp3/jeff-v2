# Jeff, o Tubarãozinho da Terra 🦈

> Um bot de Discord interativo com inteligência artificial integrada, focado em trazer uma personalidade única, memória de longo prazo e interações dinâmicas para o servidor.

---

## 🛠️ Sobre o Projeto

O **Jeff** nasceu como um bot voltado para mini-games (pesca, gacha, entre outros). Para elevar o nível de imersão e o engajamento dos membros, o projeto evoluiu: agora ele conta com uma **IA inteligente e adaptativa no seu core** (utilizando a API da Groq/Llama), capaz de lembrar interações passadas, reconhecer identidades, criar laços de afinidade com os usuários e mapear o contexto social do servidor.

---

## 🏗️ Status do Projeto

⚠️ **Em desenvolvimento ativo!** Novas funcionalidades, melhorias de prompt e expansões do sistema de memória estão sendo implementadas constantemente.
